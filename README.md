# romsite

Database and website for an emulator catalog (GameCube, Wii, Wii U and more), built with MySQL.

## Getting started

```
git clone https://github.com/WCM20XXv/romsite
```

Before you start working each time, run `git pull`. When you're done:

```
git add .
git commit -m "what you changed"
git push
```

Never commit passwords. Put them in a `.env` file, which `.gitignore` keeps out of the repo.
